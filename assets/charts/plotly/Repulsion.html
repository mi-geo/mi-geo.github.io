Spatial simulation

Testing whether two kinds of places tend to push away from each other.

This page is a compact visual story about a repulsion hypothesis. The question is whether communist camps, or kompro, and Islamic boarding schools, or pesantren, were arranged more separately than we would expect under a non-repulsive random pattern.

What the comparison is doing

I generated many alternative spatial arrangements under a model that relaxes the idea of repulsion. Then I compared those simulated configurations to the real one using a pair of minimum-distance statistics.

The setup

The substantive question

If kompro and pesantren were not repelling each other in space, then many other arrangements should have been possible. A simulation lets us ask whether the observed pattern still looks ordinary once those alternatives are generated at scale.

The two metrics

  • Minimum distance among simulated kompro locations
  • Minimum distance from kompro locations to pesantren

The empirical point in context

The observed configuration appears against the wider simulated distribution in the same minimum-distance metric space.

The purpose is not just to show one point. It is to ask whether the real pattern lands in a common region of the simulated world or whether it sits at the margins of what the non-repulsive model usually produces.

A surface view of the same question

This is a 3D histogram surface. Each cell records how many simulated arrangements fall into that minimum-distance bin, while the dot marks the observed configuration.

How to read it

The chart turns the simulation into a landscape. Dense areas mean the random non-repulsive model generates those combinations often. Sparse areas mean it rarely does.

  • A = minimum distance to pesantren
  • B = minimum distance among simulated kompro
  • Z = simulation count
  • The dot marks the observed data point

What the figure suggests

If the point sits in a dense region

Then the real arrangement looks fairly consistent with the random model. The observed minimum-distance pair would not be especially surprising.

If the point sits near an edge or sparse region

Then the real arrangement looks harder to explain with the non-repulsive model alone. That is the more interesting outcome here, because it suggests the observed geography was not just one ordinary draw from a neutral arrangement process.

This page keeps the visual argument compact: simulate many possible worlds, place the observed world inside them, and see whether it still looks ordinary.
